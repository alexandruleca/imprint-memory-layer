# profiles. Setup keeps it only when llama.cpp finds a GPU, and installs

# offloads to any NVIDIA, AMD or Intel GPU through the graphics driver alone:
# no CUDA toolkit, no compiler. The Vulkan loader (vulkan-1.dll /
# libvulkan.so.1) is a hard dependency; machines without it fail setup's
# offload check and get the CPU wheel.
#
# Every other platform is the same as llm.txt: macOS's wheels include Metal,
# so it offloads too; Linux arm64 and the rest run on CPU.
