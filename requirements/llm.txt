# prebuilt CPU wheel for the platform, install that release asset instead
# (ADR 0035). Other platforms build the same version from source; on macOS
# that build enables Metal (upstream's Metal wheel is not used: its archive
# fails CRC checks).
#
# GPU profile + --with-llm force-rebuilds this wheel with CUDA support —
# see ensureLlamaCppGPU in cmd/setup.go.
