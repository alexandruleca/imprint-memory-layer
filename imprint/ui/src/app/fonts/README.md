# Inter

Unmodified variable font and SIL Open Font License from Google's font repository,
revision `1c627bfa375fc51cf86fabeca4f6e08a95f0aa5c`:

- https://github.com/google/fonts/blob/1c627bfa375fc51cf86fabeca4f6e08a95f0aa5c/ofl/inter/Inter%5Bopsz,wght%5D.ttf
- https://github.com/google/fonts/blob/1c627bfa375fc51cf86fabeca4f6e08a95f0aa5c/ofl/inter/OFL.txt

The source filename is renamed to `Inter-Variable.ttf`. The license is served as `public/licenses/Inter-OFL.txt`. Keep it with
redistributions. `next/font/local` bundles the font without a Google Fonts
request during builds or dashboard use. Inter is also the website's typeface.
